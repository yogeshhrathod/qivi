# Qivi

A customizable particle-based AI companion for React, maintained by [Yogesh Rathod](https://github.com/yogeshhrathod).

The reusable npm package lives in [library/qivi](library/qivi). This repository also includes a demo with a mock chat backend.

## Development

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run build:library
npm test --prefix library/qivi
```

## Package

The intended npm package name is `@yogeshhrathod/qivi`. See the [package README](library/qivi/README.md) for usage and release instructions. The repository is private during release preparation; the package has not been published.
